# Kvasir v1.0.0 — Connector Architecture

Первый публичный выпуск обновлённого Kvasir. Бот перенесён на архитектуру, в которой Discord и медиабиблиотеки находятся за отдельными коннекторами, а очередь, плейлисты и воспроизведение не зависят от их API.

## Главное

- NetCord с поддержкой обязательного голосового протокола Discord DAVE/E2EE;
- отдельные `IBotConnector` и `IBotVoiceConnection` для быстрой замены Discord SDK;
- отдельные медиаконнекторы для Spotify, YouTube, `yt-dlp` и FFmpeg;
- обновлённый `yt-dlp` и резервное переключение загрузчика;
- трек попадает в очередь только после успешной загрузки;
- интерактивная музыкальная панель, плейлисты, история и популярные треки;
- SQLite, структурированные журналы и автоматическая проверка архитектурной границы;
- конфиденциальная конфигурация исключена из Git и релиз проверяется на секреты перед публикацией.

## Запуск

1. Установите .NET 10 Runtime для Windows x64.
2. Распакуйте архив.
3. Положите `ffmpeg.exe`, `ffplay.exe` и `ffprobe.exe` в папку `appdata`, если их нет в архиве.
4. Задайте переменную окружения `KVASIR_DISCORD_TOKEN`.
5. Запустите `Kvasir.exe`.
6. Выполните `/anchor` в текстовом канале, затем `/play` из голосового канала.

Spotify остаётся необязательным: без его ключей поиск и загрузка через YouTube продолжают работать.
