# Архитектура Kvasir

Бизнес-логика бота не должна знать, какая Discord-библиотека используется.

## Зависимости

```text
Entities <- Application <- Infrastructure
                   ^               ^
                   |               |
       Kvasir.Media         src/Kvasir/Connectors (Discord)
          ^                            ^
          |                            |
 Spotify/YouTube/yt-dlp             NetCord
```

- `Entities` содержит сущности и перечисления.
- `Application` содержит очередь, воспроизведение, плейлисты и построение модели музыкального интерфейса.
- `src/Application/Interfaces/IBotConnector.cs` описывает сообщения, каналы и подключение к голосу, которые нужны приложению.
- `src/Application/Models` содержит собственные модели платформы. Здесь запрещены типы NetCord.
- `src/Kvasir/Connectors/NetCordBotConnector.cs` переводит собственные модели приложения в NetCord и обратно.
- `src/Kvasir.Media/Kvasir.Media.sln` собирает библиотеку поиска, загрузки и обработки через Spotify, YouTube, yt-dlp и FFmpeg. У библиотеки нет ссылок на другие проекты решения. Адаптер в `src/Connectors/Media` принимает сущности песен Kvasir. Кэшем файлов и SQLite управляет `Infrastructure`.
- WPF раз в секунду читает снимок медиаопераций по отдельному каналу `-media` с ключом текущего сеанса. Снимок доступен и во время поиска в основном канале. Он содержит этап работы, объём и процент загрузки при известном размере, обработанное время FFmpeg или причину ошибки.
- `src/Kvasir/Commands` и `src/Kvasir/Handlers` являются входными адаптерами: они принимают события NetCord и передают в `Application` только собственные модели и простые значения.
- `Infrastructure` реализует хранение данных и не зависит от Discord-библиотеки.
- `Kvasir.Desktop` — WPF-пульт с настоящим NuGet-пакетом Tessera.WpfStyles. Он запускает `Kvasir` как дочерний процесс, показывает stdout/stderr и получает снимки/отправляет команды через именованный канал Windows. В нём нет ссылок на Discord, Entity Framework и медиабиблиотеки.
- `Kvasir.Control` содержит только транспортные DTO и JSON-протокол с ограничением кадра 8 МиБ; его используют оба процесса. Музыкальная бизнес-логика в нём отсутствует.
- `Kvasir.Configuration` определяет общую папку `%LOCALAPPDATA%\Kvasir` через `Environment.SpecialFolder.LocalApplicationData`, путь конфигурации и расположение исполняемых зависимостей. Пульт и бот используют один файл независимо от каталога установки и рабочего checkout. Существующий файл не заменяется шаблоном.
- `src/Kvasir/DesktopControl/DesktopControlService.cs` — входной адаптер локального оператора. Он получает серверы/голосовые каналы через NetCord, а действия выполняет через существующие `GuildService`, `MusicClientService`, `IMusicLibrary`, `IMediaCache` и `IMusicDiagnostics`. Discord Components V2 и WPF работают с теми же экземплярами сервисов и данными.
- Имя канала и ключ сеанса случайны и передаются дочернему процессу через окружение. Сервер и клиент используют `PipeOptions.CurrentUserOnly`. Локальный оператор считается администратором; заказчиком и автором его подборок служит Discord ID бота. Правила участников Discord сохраняются.
- `vendor/nuget` содержит Tessera.WpfStyles 0.1.0 для сборки из чистого клона. Лицензии MIT/OFL находятся рядом и включаются в публикацию WPF.

Схема управления: `WPF → Kvasir.Control / named pipe → DesktopControlService → существующие сервисы Application / Infrastructure`. Транспорт не сохраняет вторую очередь; WPF обновляет снимок каждые две секунды, после команды — сразу. Изменяющие команды после разрыва связи автоматически не повторяются.

Закрытие WPF отправляет `stop` в stdin (`KVASIR_CONTROL_STDIN=1`) и ждёт завершения процесса. По тайм-ауту окно остаётся открытым: принудительное убийство процесса не используется. Host получает до пяти минут на штатное завершение активных операций. Публикация включает только шаблон конфигурации и исключает рабочую SQLite-базу.

## Как заменить Discord-библиотеку

1. Создать новый коннектор, реализующий `IBotConnector` и `IBotVoiceConnection`.
2. Создать маппинг серверов, каналов и сообщений в модели из `src/Application/Models`.
3. Переписать только регистрацию клиента, команды и обработчики событий в запускаемом проекте.
4. Зарегистрировать новый коннектор как `IBotConnector`.
5. Выполнить `scripts/check-architecture.ps1` и собрать решение.

Классы `GuildService`, `MusicClientService` и `MusicViewService` при такой замене изменяться не должны.

Для замены Spotify, YouTube или загрузчика реализуется `IVideoFinderService` либо `IAudioDownloaderService` в медиабиблиотеке или адаптере `Connectors`. Ядро и репозитории зависят только от этих интерфейсов.

## Голос

`Application` пишет PCM 48 kHz, stereo, signed 16-bit в поток, который возвращает `IBotVoiceConnection.CreatePcmStream()`. Кодирование Opus и отправка пакетов являются обязанностью коннектора. Поэтому смена voice API или кодека конкретной Discord-библиотеки не затрагивает музыкальную очередь.

## Секреты

Основной источник Discord-токена — первый элемент массива `tokens` в `%LOCALAPPDATA%\Kvasir\configuration.json`. Бот читает его при каждом запуске, конфигурация имеет приоритет перед переменной окружения. Консольный запуск дополнительно поддерживает `KVASIR_DISCORD_TOKEN`, если в файле нет токена.

Пульт показывает путь и открывает конфигурацию в отдельном окне настроек. Его SVG-кнопка находится в заголовке слева от сворачивания; тема сохраняется в `desktop-settings.json` в той же папке AppData. Заголовок использует WPF WindowChrome с изменением размера и кнопками управления окном. Оригинал шестерёнки — отдельный файл `src/Kvasir.Desktop/Assets/Icons/settings.svg`.

Рабочая папка бота — папка данных AppData: относительные пути базы, кэша и настроек серверов отсчитываются от неё. Журналы также находятся в AppData. Абсолютные пути из пользовательской конфигурации сохраняются. FFmpeg, yt-dlp, Opus и DAVE разрешаются относительно каталога исполняемого файла. Бот располагается в `bot` рядом с пультом; MSBuild готовит эту папку при сборке, поиск репозитория во время работы отсутствует. Пульт держит токен в памяти только для маскирования журнала; токен дочернему процессу через окружение не передаётся.
