# Kvasir v1.1.4

Скачайте **Kvasir-v1.1.4-win-x64.exe** и запустите его. Один файл содержит десктопный пульт, бота, .NET, FFmpeg и yt-dlp. При первом запуске приложение распакует встроенные файлы в пользовательский кэш .NET. Установщик не требуется.

**Kvasir-v1.1.4-win-x64.zip** подходит для запуска из распакованной папки. Откройте Kvasir.Desktop.exe после распаковки.

Токен бота и настройки хранятся в %LOCALAPPDATA%\Kvasir. При обновлении можно заменить EXE и продолжить с текущими настройками.

## Сторонние компоненты

FFmpeg 9.1 и yt-dlp 2026.11.23 запускаются отдельными процессами. Уведомления о лицензиях включены в каталог bot/licenses обоих комплектов.
