## Загрузка

Скачайте **Kvasir-{version}-win-x64.exe** и запустите его. Один файл содержит десктопный пульт, бота, .NET, FFmpeg и yt-dlp. При первом запуске приложение распакует встроенные файлы в пользовательский кэш .NET.

Для запуска из распакованной папки скачайте **Kvasir-{version}-win-x64.zip** и откройте Kvasir.Desktop.exe.

Токен бота и настройки хранятся в `%LOCALAPPDATA%\Kvasir`.

## Сторонние компоненты

FFmpeg 9.1 и yt-dlp 2026.11.23 запускаются отдельными процессами. Уведомления о лицензиях находятся в каталоге `bot/licenses`.

- [Сборка FFmpeg для Windows](https://github.com/GyanD/codexffmpeg/releases/tag/9.1) · [исходный код FFmpeg](https://github.com/FFmpeg/FFmpeg/tree/74e4393595)
- [Сборка и исходный код yt-dlp](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.11.23)
