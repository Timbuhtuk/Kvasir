## Найденные ошибки и исправления

Это воспроизведённые случаи, а не статистика частоты. Для повторяющихся типов сбоев заведены отдельные причины и действия восстановления.

| Случай | Наблюдение | Исправление и проверка |
|---|---|---|
| Discord отклонил токен, 401 | Бот завершался при авторизации | Защищённое окно «Discord отклонил токен», сохранение и повторный запуск. Новый токен принят, следующие запуски успешны |
| Устаревший статус после выхода процесса | Ожидание ответа могло перекрыть итоговый статус | Отмена запроса больше не перезаписывает завершённое состояние |
| Не выбран голосовой канал | Добавление не могло начаться | Диалог с причиной и кнопкой «Выбрать канал»; переход к выбору проверен |
| YoutubeExplode не читает watch page | Получено «Video watch page is broken» | Метаданные и скачивание переведены на уже включённый yt-dlp; публичный ролик успешно проходит весь путь в пульте |
| Зависание нативного загрузчика | Получен тайм-аут в ранних вариантах запуска | Отдельный процесс с асинхронным чтением обоих потоков, закрытым stdin, лимитом времени и остановкой только собственного дерева. Отдельная модалка «Источник не отвечает» |

| Ограничение входного расширения FFmpeg | Загруженный WebM/M4A не проходил старую проверку `.mp3` | Контейнер определяет FFmpeg; реальное преобразование в PCM прошло |

## Изолированные и нативные проверки

Сборка решения Release с предупреждениями как ошибками: **0 предупреждений, 0 ошибок**. Self-contained публикации бота и WPF для win-x64 завершились успешно.

- **Kvasir.Tests: 165 проверок.** Очередь и порядок разных треков, ограничения/права, SQLite-библиотека, редактирование, частичный импорт с сохранением успешной части, отдельная локальная причина ошибки, кэш и безопасные пути, воспроизведение с тестовым голосовым коннектором, пауза/продолжение, перемотка, голосование, повтор/остановка, PCM-громкость, Components V2 и настоящий FFmpeg.
- **Kvasir.Desktop.Tests: 88 проверок.** Отсутствие/сохранение/повторное чтение токена, сохранение остальных параметров JSON, отказ без перезаписи при неверном вводе, специальные диалоги и восстановление, независимые черновики вкладок, layout пяти разделов при минимальном и обычном размерах, доступность содержимого WPF.
- **Отдельный live-media-probe: 3 проверки.** Настоящие метаданные и скачивание публичного ролика, FFmpeg → PCM, 3 649 064 байта (около 19 секунд). Финальный прогон завершился примерно за 6 секунд.
- `scripts/check-architecture.ps1`: граница Application / Connectors соблюдена.

Тесты используют свои временные каталоги, синтетические токены и тестовую SQLite-базу. Рабочий токен не заменяется. Ограниченная песочница запрещала атомарное перемещение временного файла и сетевое разрешение имён; проверки с нативными процессами повторены в обычном окружении Windows.

